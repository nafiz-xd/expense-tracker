# Expense Tracker 💰

A simple daily **income & expense tracker** that runs entirely in your browser.

## 🔗 Live Demo
👉 https://nafiz-xd.github.io/expense-tracker/

## ✨ Features
- Add income & expense entries with category and date
- Live balance, total income and total expense summary
- Expense-by-category visual breakdown
- Data saved in your own browser (localStorage) — private, no sign-up, no server
- Delete any entry anytime

## 🛠️ Tech
HTML • CSS • JavaScript • localStorage — single page, hosted on GitHub Pages.
